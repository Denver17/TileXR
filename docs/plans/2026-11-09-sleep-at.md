# Clock sleep_at implementation

## Approved contract

`TileXRClockSleepAt(detector, referenceCycle, stream)` asynchronously enqueues
one AIV on the caller's stream. The signed absolute cycle uses logical
communicator rank 0's timeline, as returned by `TileXRClockCorrectCycle`.
The invocation snapshots the local READY drift model and rounds its inverse
up to a local integer deadline. A past deadline returns from the kernel
immediately. Invalid/unready models or an unrepresentable deadline fail before
launch. The call does not calibrate or communicate with peers.

## Work and acceptance

1. Rebase the existing debug branch on main and preserve it; create a feature
   branch from main so this change excludes unrelated queue diagnostics.
2. Add checked inverse model arithmetic, the public API, session stream
   tracking and a standalone CCE entry registered by the diagnostics library.
   Preserve C++14 Host support, existing struct ABIs and CANN 9.1 conventions.
3. Cover affine inversion, rounding, large epochs, invalid states and overflow
   on CPU. Exercise asynchronous submission, model snapshots, owner-thread
   checks, launch failure and destroy retry with the existing runtime hooks.
4. Add a real-device integration case measuring downstream device cycles and
   Host submission time after future, expired and repeated queued deadlines.
   Build/install with the supported CANN toolchain; validate on devices 0/2
   using the already qualified cross-NIC clock path. No network configuration
   changes or repeated AllReduce qualification are part of this work.
5. Document stream lifetime, model accuracy limits and the distinction between
   busy waiting on an AIV and suspending device execution. Review the final
   diff, run focused checks, commit and normally push the task branch for
   protected-environment validation through the existing cross-zone workflow.

## References and risks

- `src/include/tilexr_straggler.h`: model and public API contracts.
- `src/diagnostics/host/straggler_session.cpp`: ownership and pending streams.
- `src/diagnostics/host/clock_kernel.cpp`: standalone binary registration.
- `docs/specs/2026-08-25-common-straggler-diagnostics-design.md`: affine model.
- Numeric conversion must avoid unsigned subtraction wrap and early wake from
  truncation. A frozen model gives model-relative scheduling, not a guarantee
  of physical clock alignment; a stream may start the kernel after its deadline.
- Kernel waiting consumes an AIV and remains subject to runtime task timeout.
